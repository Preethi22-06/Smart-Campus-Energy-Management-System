# Users of Smart Campus Energy Management System

## 1. Maintenance Staff

Responsibilities:
- Check which rooms have appliances ON.
- Visit only the required rooms.
- Save inspection time.

Can View:
- Buildings
- Floors
- Rooms
- Light Status
- Fan Status

-------------------------------------

## 2. Hostel Warden

Responsibilities:
- Monitor hostel rooms and common areas.
- Reduce electricity wastage.

Can View:
- Hostel Blocks
- ClassRoom Status
- Reports

-------------------------------------

## 3. College Administrator

Responsibilities:
- Monitor overall electricity usage.
- View reports.
- Track monthly savings.

Can View:
- Everything
