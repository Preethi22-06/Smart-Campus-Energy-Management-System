# System Flow

## Maintenance Staff

1. Open the application.
2. Login with username and password.
3. Dashboard opens.
4. View overall campus status.
5. If there are rooms requiring inspection:
   - Select the building.
   - View the room details.
   - Visit the room and switch OFF the appliance manually.
6. If there are no issues:
   - Display "Everything is OK".

---

## Administrator

1. Login.
2. View campus dashboard.
3. View reports.
4. Monitor electricity usage.
5. View statistics.
