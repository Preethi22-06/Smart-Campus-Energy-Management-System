# Smart Campus Energy Management System

## Version 1 Features

### Authentication
- Admin Login

### Dashboard
- Display all buildings
- Display all rooms
- Show Light Status (ON/OFF)
- Show Fan Status (ON/OFF)

### Search
- Search room by room number

### Filter
- Filter rooms by building

### Room Details
- Room Number
- Building Name
- Floor Number
- Light Status
- Fan Status
